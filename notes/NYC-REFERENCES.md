# NYC reference sources and data gaps

This is a short source list for Manhattan below 59th Street. Links are for research and potential local data preparation; verify each item’s own license and attribution before bundling it.

## Trees and street landscape

- [NYC 2015 Street Tree Census on NYC Open Data](https://data.cityofnewyork.us/Environment/2015-Street-Tree-Census-Tree-Data/uvpi-gqnh) — authoritative record-level source, with coordinates and species (`spc_common` / `spc_latin`) alongside health and site fields. Useful for real tree placement and species proportions in Manhattan. It is a street-tree census, not a complete inventory of Battery Park City park interiors or private plantings; it is from 2015 and should not be represented as current planting status. The dataset page offers a CSV export.
- [LarryHH/nyc-street-trees](https://github.com/LarryHH/nyc-street-trees) — accessible GitHub mirror explicitly sourced to that census. Its [raw `trees_data.js`](https://raw.githubusercontent.com/LarryHH/nyc-street-trees/main/trees_data.js) contains 683,788 `[longitude, latitude]` pairs, fetched 2026-08-28. The raw file is 14.2 MB, citywide and locations only: species and other attributes were discarded. No explicit repository license was apparent, so use the NYC Open Data source for reusable data and use this mirror only as a quick location reference unless its license is clarified. A Manhattan-only crop would reduce the payload but still would not add species.
- [Battery Park City Authority parks](https://bpca.ny.gov/parks/) and [Battery Park City Parks Conservancy](https://bpcparks.org/) — place-specific names and park descriptions for the BPC greenway and parks; useful to orient photo research and identify the intended landscape. These pages are not a machine-readable planting schedule or a complete species inventory. For materials and plant choices, consult BPCA project/design documents linked from the Authority site and treat them as project-specific, not a current as-built survey.
- [NYC Parks: The Battery](https://www.nycgovparks.org/parks/battery-park) — official location/context reference for the Battery (separate from BPC). Useful for park identity and current official photos; not a street-tree inventory.
- [Wikimedia Commons: Battery Park City](https://commons.wikimedia.org/wiki/Category:Battery_Park_City), [Teardrop Park](https://commons.wikimedia.org/wiki/Category:Teardrop_Park), and [South Cove](https://commons.wikimedia.org/wiki/Category:South_Cove) — actual place photos can show paving, edges, benches, planting layers, and nearby architecture. Check the individual file page for date, viewpoint, and license/attribution; a category page itself grants no blanket reuse right. Photos support visual reference, not measured materials or confirmed species.

## Building and landmark form

- [NYC 3D Building Model in rolyatmax/nyc-buildings](https://github.com/rolyatmax/nyc-buildings) — the existing 2014 LOD2 surveyed roofs remain the best broad, downloadable mesh source found for this project’s lower-Manhattan area. The dataset is dated and misses later construction; it is already incorporated in Birdway, so this is provenance rather than a new upgrade.
- `/workspace/scratch/landmark-parts.geojson` — a local 609-feature set of tagged OpenStreetMap building-part polygons across 23 named landmarks. It is useful for extruding tower tiers/crowns by `min_h_m` and `h_m`; the One World Trade Center entry has nine part polygons with height intervals, for example. It can improve a few landmark silhouettes beyond a single footprint, but it is not a surface mesh, is limited to selected landmarks, and OSM tagging/part boundaries may be incomplete or overlapping. OSM-derived data is ODbL; attribute OpenStreetMap and keep the derived database under ODbL as documented in Birdway’s credits.
- [OpenStreetMap building parts](https://wiki.openstreetmap.org/wiki/Key:building:part) and [ODbL 1.0](https://opendatacommons.org/licenses/odbl/1-0/) — explains interpretation and reuse terms for the local part polygons. Treat heights and outlines as mapped estimates, not a contemporary engineering survey.
- [Wikimedia Commons: One World Trade Center](https://commons.wikimedia.org/wiki/Category:One_World_Trade_Center), [Battery Park City](https://commons.wikimedia.org/wiki/Category:Battery_Park_City) — real views of the WTC crown, podium, glazing, and BPC skyline for visual checks. Select files individually and record their licenses; photographs are not geometry or permission to reproduce protected design details as a texture.

## Practical conclusion

The strongest actionable tree improvement is a filtered slice of the NYC Open Data census, retaining each tree’s coordinates and species; do not derive species from the GitHub coordinate-only mirror. For BPC planting, current place photos and BPCA project records are useful visual references, but no compact, openly licensed, current planting inventory was identified. For buildings, the local OSM parts can add a small number of tiered landmark forms, while the 2014 LOD2 survey still covers the broadest Manhattan mesh area available in the sources checked; no newer openly downloadable full-mesh replacement was identified.
