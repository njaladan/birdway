Birdway facade texture maps

color.jpg, height.jpg, and roughness.jpg are 2048 x 1024 atlases generated by
../tools/prepare-facade-textures.py. Each tile covers a 3 m facade span by one
3.3 m floor, arranged in facadeKind order 0 through 7. The color atlas is sRGB;
height and roughness are linear data maps. Kind 4 (curtain wall) is original
procedural artwork. The other tiles use real ambientCG PBR photographs/maps,
resampled to 512 x 512 and packed in the atlas.

Source texture packs, all CC0 1.0 Universal:
- Bricks066, ambientCG: https://ambientcg.com/view?id=Bricks066
- Concrete012, ambientCG: https://ambientcg.com/view?id=Concrete012
- Metal063, ambientCG: https://ambientcg.com/view?id=Metal063

source/ so the atlases can be rebuilt offline. AmbientCG asks no attribution;
these references are included as credits and provenance.
